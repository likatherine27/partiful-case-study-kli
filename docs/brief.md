# Project Brief

## Business Operations Associate Take-home: Change Phone Number

### Background

Within Partiful, you can change your phone number self-serve. However, it requires that you have access to your previous number, which isn't always the case.

When a user hits this issue, they reach out via hello@partiful.com and it gets assigned to our support team. Currently, this is a highly manual process:

1. The user reaches out requesting a phone number change.
2. This gets assigned to someone from our support team, who first asks if they have access to their old phone.
3. If the user says they have access to their old phone, they are redirected to change their phone number self-service via logging in (see instructions [here](https://help.partiful.com/hc/en-us/articles/26025082969243-Can-I-change-my-phone-number)).
4. If the user says they have lost access to their old phone, we request that they submit ID verification to confirm their identity.
5. If we are able to verify the ID, we will proceed with the phone number change.

Instead of this time-consuming process, we want to move to an agentic workflow that requires as minimal human involvement as possible to streamline & free up time of the support team.

### Tasks

- Write a scoping document for an MVP solution.
- Build an agent to the specifications of the scoping document, using any tool you wish.
  - Where you would be integrating with an internal API, for example for committing the phone number change, instead just print the action in the agent interface.
  - Feel free to make assumptions about how this would work in Partiful's internal environment, and document any assumptions made into your scoping document.
- Build an appropriate test set to test your agent.
- Record a demo of the agent completing the test set. Share the recording, the agent (in whatever form is easiest), and the test set in your submission.
- Now that an MVP has been built, what improvements can be made that didn't make it into MVP? Provide a brief explanation of what the change/improvement is, and why it didn't make it into MVP.

### Submission

Submit a written document, a link to the agent, the test set, and a video recording of the solution, within 48 hours of receiving the take-home.
